# История изменений

Все значимые изменения в этом проекте будут документированы в этом файле.

## [0.3.0] - 2025-11-12

### ✨ Добавлено
- **JMX Мониторинг**: Поддержка JMX Prometheus Exporter для экспорта метрик Kafka
  - Метрики брокеров (throughput, latency, partition stats)
  - Метрики consumer/producer групп
  - Метрики топиков
  - JVM метрики (memory, GC, threads)
  - Операционные метрики
- **Новый профиль**: `values-jmx.yaml` с включенным JMX мониторингом
- **ConfigMap для метрик**: `metrics-configmap.yaml` с детальными правилами экспорта
- **Параметр `jmx.enabled`**: Управление включением/выключением JMX

### 🔧 Изменено
- **kafka-kraft.yaml**: Добавлена секция `metricsConfig` с условной загрузкой
- **values.yaml**: Добавлена секция `jmx` (по умолчанию выключено)

### 📚 Документация
- Обновлены `VALUES_REFERENCE.md` и `VALUES_REFERENCE.en.md` с информацией о JMX
- Обновлены `README.md` и `README.en.md` с информацией о новых возможностях
- Добавлены примеры использования JMX

## [0.2.0] - 2025-10-20

### ✨ Добавлено
- **Множественные режимы развертывания**: Поддержка трех сценариев развертывания
  - `single-node`: Один узел для разработки (1 реплика, фактор репликации = 1)
  - `dual-role`: Узлы с двумя ролями для staging (3 реплики, broker + controller)
  - `separated-roles`: Отдельные пулы controller и broker для production
- **Гибкая конфигурация хранилища**: Поддержка persistent, ephemeral и JBOD типов хранилища
- **Автоматическая конфигурация факторов репликации**: Факторы репликации автоматически адаптируются в зависимости от режима развертывания
- **Готовые к использованию конфигурационные профили**:
  - `values-single-node.yaml` для локальной разработки
  - `values-dual-role.yaml` для staging окружений
  - `values-separated-persistent.yaml` для production с persistent storage
  - `values-separated-ephemeral.yaml` для тестирования с ephemeral storage
- **Вспомогательные шаблоны**: Добавлен `_helpers.tpl` с утилитарными функциями для динамической конфигурации
- **Улучшенный NOTES.txt**: Детальная информация о развертывании с рекомендациями для конкретного режима
- **Полная документация**: Обновлен `VALUES_REFERENCE.md` с полной документацией параметров

### 🔧 Изменено
- **values.yaml**: Реструктурирован для поддержки множественных режимов развертывания
- **node-pool.yaml**: Сделан динамическим для поддержки всех сценариев развертывания
- **kafka-kraft.yaml**: Улучшен автоматическим расчетом факторов репликации
- **README.md**: Обновлен с примерами режимов развертывания и руководством быстрого старта

### 📚 Документация
- Полная справка по параметрам в `VALUES_REFERENCE.md`
- Английская документация в `VALUES_REFERENCE.en.md`
- Примеры использования для каждого сценария развертывания
- Руководство по миграции между режимами развертывания
- Двуязычная документация (русский и английский)
