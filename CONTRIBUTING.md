# Вклад в проект

Спасибо, что хотите помочь проекту! Ниже — краткие правила.

## Как начать
- Форкните репозиторий и создайте ветку от `main`.
- Установите требования (Helm 3, доступ к Kubernetes, установлен Strimzi Operator 0.48.0).
- Работайте в каталоге чарта `kafka-cluster`.

## Коммиты и PR
- Делайте небольшие логически цельные изменения.
- Сообщения коммитов в формате: `scope: краткое описание`.
- Описывайте в PR проблему, решение, как протестировать.
- Связывайте PR с issue (например, `Closes #123`).

## Стиль
- Не меняйте форматирование без необходимости.
- Шаблоны Helm: придерживайтесь существующей структуры и именований значений в `values.yaml`.

## Тестирование
- Проверяйте рендер: `helm template ./kafka-cluster -f kafka-cluster/values.yaml`.
- Проверяйте установку на тестовом кластере.

## Кодекс поведения
Участие означает согласие с `CODE_OF_CONDUCT.md`.

## Безопасность
Уязвимости не публикуйте в issue — следуйте `SECURITY.md`.
